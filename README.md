# ScamAnchor

### *Grounded scam intelligence, with a human in the loop.*

**🔗 Live case study → https://tommyasni08.github.io/scam-anchor/**

ScamAnchor is a solo, end-to-end prototype: an LLM classifier for scam reports that's
grounded in a structured knowledge base of real Singapore scams and validated against it
— so it can't silently invent a scam category, pattern, or value that doesn't exist.

This repo hosts the **case study** — a single static page, served via GitHub Pages. The
classifier and taxonomy source code are kept private by design.

Built by **Tommy Asni**. Open the [live page](https://tommyasni08.github.io/scam-anchor/)
for the full write-up, and use the contact link there to get in touch.
